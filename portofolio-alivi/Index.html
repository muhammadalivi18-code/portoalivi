⭐ Proyek PKL

Sistem Absensi Kantor Desa Dayeuh

Website absensi dengan dua peran, Admin dan Karyawan. Admin memantau kehadiran real-time (hadir, telat, izin, sakit, alfa), mengelola data karyawan, dan input manual. Karyawan absen masuk dan pulang dengan verifikasi wajah lewat kamera, lengkap dengan foto bukti dan riwayat kehadiran.
